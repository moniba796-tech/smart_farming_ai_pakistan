# اردو ٹیوٹوریل ویڈیو اسکرپٹ
## Smart Farming AI Pakistan — کیسے استعمال کریں

> **Note for the developer:** Claude cannot generate actual video/audio files.
> This is a complete, ready-to-record script — record it yourself (phone
> screen-recording + your voice, or a text-to-speech tool), then upload the
> finished video to YouTube (unlisted is fine) and paste its video ID into
> `frontend/.env` as `VITE_TUTORIAL_YOUTUBE_ID`. It will then automatically
> appear embedded on the app's `/how-to-use` page — no code changes needed.
>
> Estimated runtime: ~3-4 minutes. Record each numbered scene while
> screen-recording the matching part of the real app for best results.

## Recording Tips

- Use your phone's built-in screen recorder while narrating live, or record narration separately and sync it in a free video editor (CapCut, DaVinci Resolve).
- Keep each scene under 30-40 seconds — matches the app's own pacing well.
- Speak slowly and clearly — many farmers watching this may not be reading along, only listening.
- Once uploaded to YouTube, get the video ID from the URL (the part after `v=`, e.g. `https://youtube.com/watch?v=ABC123xyz` → ID is `ABC123xyz`) and set it as `VITE_TUTORIAL_YOUTUBE_ID=ABC123xyz` in `frontend/.env`.
